# Conventions

Three files, one question each.

- [`css.md`](css.md) — there are five stylesheets and only one of them may be edited.
- [`templates.md`](templates.md) — what a Handlebars template is allowed to do, and what has to
  happen in `ghost-bridge.js` instead.
- [`extract.md`](extract.md) — how a value gets from the blog engine to here.

The rule underneath all three: **this theme has no design of its own.** Every visual decision
was made in Quire Ink and measured there. When something looks wrong here, the question is
which of its decisions failed to come across — not what would look better.
